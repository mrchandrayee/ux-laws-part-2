A responsive, interactive recreation of the 85.1-second reference video.

## The six laws shown
1. Goal Gradient — Never start at zero.
2. Postel's Law — Accept it any way.
3. Tesler's Law — Someone carries the work.
4. Similarity — Alike means works alike.
5. Serial Position — First and last stick.
6. Peak-End Rule — End on a high.

## Run locally
No build tools or dependencies are required.

```bash
python3 -m http.server 8000
```
Open http://localhost:8000

You can also open `index.html` directly in a modern browser.

## Interactive examples
- Goal gradient: zero-start versus two-stamp head start reward cards.
- Postel's Law: phone input examples and a forgiving 10-digit input.
- Tesler's Law: sample ZIP-code lookup auto-fills city/state/street.
- Similarity: consistent tappable settings rows with detail feedback.
- Serial position: interactive navigation item selection.
- Peak-end rule: cold versus warm completion-state comparison.

## Source fidelity
The reference video displays a designed infographic and UI examples, not the creator's HTML/CSS/JS source files. This project is a clean-room, responsive recreation of the visible content and concepts. Numerical comparisons and example values are reproduced where legible; UI interactions are implemented as local demonstrations, not connected to real services or external APIs.
